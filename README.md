### Protobot Rebuilt

This repository is a fork of BreadSoup/Protobot-Rebuilt

Minimal patches to get command working and other polishes for Mac OS

- [x] Command Z & Y functionality & Proper Support for Remapping 

- [ ] Native Menu Bar

- [ ] Native Pref Plane

Get the latest release from [releases](https://github.com/ZimengXiong/Protobot-Rebuilt-MacOS/releases).

Run `xattr -cr /Applications/Protobot-Rebuilt.app` to clear notarization requirements.
